Política de Privacidade

Última atualização: 21 de março de 2026

1. Introdução

O Parceladinho ("nós", "nosso" ou "app") respeita sua privacidade. Esta política explica como tratamos suas informações ao usar nosso aplicativo de controle de parcelas de cartão de crédito.

2. Dados que coletamos

O Parceladinho coleta o mínimo de dados necessários para funcionar:

  • Nome do usuário: informado voluntariamente durante o onboarding, armazenado apenas no dispositivo.
  • Dados de parcelas: informações sobre compras parceladas, armazenadas localmente no dispositivo via AsyncStorage.
  • Imagens de faturas: enviadas voluntariamente para análise por IA. As imagens são processadas e não são armazenadas permanentemente em nossos servidores.

3. Como usamos seus dados

Seus dados são utilizados exclusivamente para:

  • Exibir o dashboard personalizado com suas parcelas
  • Analisar faturas enviadas para identificar compras parceladas
  • Gerar insights e projeções de gastos futuros
  • Enviar lembretes configurados por você

4. Armazenamento local

A grande maioria dos seus dados é armazenada localmente no seu dispositivo. Não mantemos cópias dos seus dados financeiros em servidores externos. Se você desinstalar o app, seus dados locais serão removidos.

5. Compartilhamento de dados e uso de IA

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins de marketing.

Quando você envia uma fatura para análise, a imagem ou PDF é transmitida para um serviço de inteligência artificial (LLM) integrado ao servidor do Parceladinho. Os dados enviados incluem: a imagem ou PDF da fatura e o nome/tipo do arquivo. O processamento é realizado exclusivamente para extrair informações de compras parceladas (loja, valor, número de parcelas). As faturas não são armazenadas permanentemente após o processamento. O serviço de IA oferece o mesmo nível de proteção de dados descrito nesta política.

O app solicita seu consentimento explícito antes de enviar qualquer dado para análise por IA.

6. Assinaturas

Assinaturas são gerenciadas pela Apple através do App Store. Não temos acesso aos seus dados de pagamento. Para gerenciar sua assinatura, acesse as configurações da sua conta Apple.

7. Segurança

Empregamos medidas técnicas para proteger seus dados, incluindo comunicação criptografada (HTTPS) para qualquer transmissão de dados entre o app e nossos servidores.

8. Seus direitos

Você pode a qualquer momento:

  • Apagar todos os seus dados diretamente no app (Configurações > Apagar todos os dados)
  • Solicitar informações sobre seus dados por e-mail
  • Desinstalar o app para remover todos os dados locais

9. Alterações nesta política

Podemos atualizar esta política periodicamente. Alterações significativas serão comunicadas através do app.
